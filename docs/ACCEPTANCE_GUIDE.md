# Abyssal Reverie v1.0.0 — 实机验收操作手册

> 适用：正式安装包 `Abyssal Reverie_1.0.0_x64-setup.exe` 与便携版 `abyssal-reverie.exe`。
> 每项按「操作 → 预期结果」执行并打勾；任何一项不符即为不通过，记录步骤号与现象。
> 建议顺序执行 A→G；时间紧张时至少完成 **A、B、C1/C2、D1/D2/D5**（P0 核心项，约 20 分钟）。

---

## 0. 准备（约 5 分钟）

### 0.1 校验安装包完整性（可选但建议）
以管理员之外的普通 PowerShell 执行：

```powershell
Get-FileHash "D:\Project\abyssal-reverie\Abyssal Reverie\src-tauri\target\release\bundle\nsis\Abyssal Reverie_1.0.0_x64-setup.exe" -Algorithm SHA256
Get-FileHash "D:\Project\abyssal-reverie\Abyssal Reverie\src-tauri\target\release\abyssal-reverie.exe" -Algorithm SHA256
```

或用 `certutil -hashfile "<路径>" SHA256`。

### 0.2 记录方式
- 复制本文件，逐项把 `- [ ]` 改为 `- [x]`（通过）或标注「不通过 + 现象」。

## A. 安装与启动

- [ ] **A1 全新安装**：双击安装包，按向导默认完成（默认当前用户安装，无需管理员）。
  预期：安装完成无报错；开始菜单出现「Abyssal Reverie」快捷方式。
- [ ] **A2 首次启动**：从开始菜单启动，同时秒表计时。
  预期：约 3 秒内主窗口出现；海洋视频背景播放；默认 25:00 空闲态；无报错弹窗。
- [ ] **A3 便携版 + 中文/空格路径**：把 `abyssal-reverie.exe` 复制到如 `D:\测试 目录\` 后直接双击运行。
  预期：正常启动、功能齐全（与安装版共用同一数据目录，数据互通属预期行为）。
- [ ] **A4 分辨率与缩放**：在 1366×768、1920×1080（及有条件时的 2K）下，Windows 显示缩放分别设 100%、150%、200% 各启动一次并缩放窗口。
  预期：布局不破、不溢出、文字清晰；拖拽窗口到最小尺寸（1024×700）仍可用。

## B. 核心计时（P0，最重要）

- [ ] **B1 开始/暂停/继续**：选一个任务（或默认未指定任务）点开始 → 倒计时递减；点暂停 → 数字停住；继续 → 接着跑。
  预期：状态切换顺畅；暂停时数字保持不变。
- [ ] **B2 快速连点防重**：运行中快速连点开始/暂停按钮多次。
  预期：无重复计时、无报错弹窗；应用无异常。
- [ ] **B3 切换即提交**：专注跑约 1 分钟后切到「短休」。
  预期：活动记录里出现一条「已完成」的专注记录（约 1 分钟，计入统计），并切换到短休。
- [ ] **B4 结束本次不计入**：短休开始后点「结束本次」。
  预期：记录显示「已中止 · 不计入」，统计数字不变。
- [ ] **B5 完整跑完一次**：设置里把专注时长临时改为 1 分钟 → 跑完。
  预期：完成音效 + 桌面通知（若开启）；今日目标环 +1；活动记录新增一条；若开启了「自动开始休息」则自动进入短休。改回 25 分钟。
- [ ] **B6 休眠/锁屏校正**：专注运行中锁屏（Win+L）或让电脑睡眠几分钟，唤醒。
  预期：剩余时间与实际流逝一致（不重置、不漂移）；若已到期，唤醒后自动完成一条记录。
- [ ] **B7 托盘退出冻结（v1.0.0 新规则，重点）**：专注运行中 → 托盘图标右键 →「退出 Abyssal Reverie」→ 重新启动应用。
  预期：应用显示「已暂停」，剩余时间 ≈ 退出前的剩余（不从头开始、不悄悄扣完）；点「继续」后可正常跑完并计入统计。
- [ ] **B8 非运行态退出**：分别在空闲 / 暂停 / 已完成状态下经托盘退出再启动。
  预期：状态原样保留，无变化。

## C. 本地数据（P0/P1）

- [ ] **C1 重启持久**：创建 2 个任务、跑 1–2 个会话、修改设置（如每日目标）→ 完全退出 → 重新启动。
  预期：任务、活动记录、设置全部还在。
- [ ] **C2 数据目录核对**：`Win+R` → `%APPDATA%\com.abyssalreverie.focus`。
  预期：能看到 `abyssal-reverie.sqlite`（目录名是应用标识 `com.abyssalreverie.focus`，不是产品名）。
- [ ] **C3 导出**：设置 → 数据 → 「导出」JSON 备份与「导出」CSV。
  预期：两个文件保存成功；CSV 用 Excel/WPS 打开表头正常、中文不乱码；JSON 可读且含 `tasks/sessions/settings`。
- [ ] **C4 导入往返**：删除一个任务 → 导入刚才的 JSON 备份。
  预期：确认弹窗显示将导入的任务/会话数；导入后被删任务恢复。
- [ ] **C5 错误导入不覆盖**：随便选一个非本应用导出的 `.json`（或手工改坏一份备份）导入。
  预期：报「校验失败」类错误被拒绝；现有任务/会话/设置**原样不动**。
- [ ] **C6 损坏自愈（可选，有点破坏性）**：完全退出应用 → 把 `abyssal-reverie.sqlite` 用记事本打开随意改乱保存 → 重新启动。
  预期：应用正常启动（数据从零开始）；原文件被重命名为 `abyssal-reverie.sqlite.corrupt-<数字>` 保留在同目录。测完可删除乱码文件；如需找回数据，把 `.corrupt-` 文件名改回 `.sqlite` 前先联系我。

## D. 桌面生命周期（P1）

- [ ] **D1 关闭驻托盘**：计时中点窗口右上角 X。
  预期：窗口消失但应用驻留托盘，托盘提示仍在更新剩余时间，计时继续。
- [ ] **D2 单实例**：应用运行中（含窗口已隐藏时）再次双击 EXE 或便携版。
  预期：不启动第二个实例；已有窗口被调起并聚焦。
- [ ] **D3 托盘操作**：左键单击托盘图标；右键查看菜单并试「开始/暂停」「结束本次」「显示窗口」。
  预期：左键显示窗口；右键菜单可用，动作与窗口内按钮一致；托盘悬停提示显示剩余时间。
- [ ] **D4 全局快捷键**：把窗口最小化到托盘，按 `Ctrl+Alt+Space`。
  预期：窗口弹出且计时开始/暂停被切换（再按一次暂停）。
- [ ] **D5 快捷键冲突降级（v1.0.0 新规则，重点）**：先用其它软件占住 `Ctrl+Alt+Space`（最简单：装 AutoHotkey，建一个只含 `^!Space::MsgBox occupied` 的脚本运行；或用截图/输入法工具的自定义热键功能设置该组合），然后启动本应用。
  预期：**应用照常启动**（不崩溃），顶部出现可关闭的警告横幅提示热键被占用；关闭横幅后其余功能全部正常。删除占用脚本、重启本应用后热键恢复。
- [ ] **D6 开机自启**：设置 → 打开「开机自动启动」→ 重启电脑（或注销再登录）。
  预期：登录后应用自动在后台运行（托盘有图标）。验证完建议关闭。
- [ ] **D7 通知关闭仍完成**：设置关闭「桌面通知」→ 跑完一个 1 分钟专注。
  预期：无通知弹出，但统计与活动记录正常 +1（完成逻辑不依赖通知）。

## E. 离线与性能（P1/P2）

- [ ] **E1 断网运行**：断开网络（拔线/关 Wi-Fi）后启动并完整使用一轮计时。
  预期：全部功能正常（安装包本身含 WebView2 离线安装器，无网机器也能安装）。
- [ ] **E2 无外部连接**：应用运行中，`Win+R` → `resmon` → 「网络」选项卡 → 在「网络活动的进程」里找 `abyssal-reverie.exe`。
  预期：该进程无对外网络连接（0 B/s 且无远程地址），逐秒刷新观察 1–2 分钟。
  等价命令行：`netstat -ano | findstr "<任务管理器里看到的PID>"` → 应无外部远程地址。
- [ ] **E3 降低动态效果**：设置 → 开启「降低动态效果」。
  预期：海洋背景静止（定格画面）；任务管理器中该进程 CPU 明显下降；关闭开关后动画恢复。系统「减少动态效果」开启时也应自动静止。
- [ ] **E4 后台开销**：最小化到托盘放置 5–10 分钟。
  预期：任务管理器 CPU 基本为 0%（视频在窗口隐藏时自动暂停）；内存稳定无持续增长。
- [ ] **E5 视频规格（可选）**：右键安装目录内 `media\ocean-loop.mp4` → 属性 → 详细信息。
  预期：1080p、H.264、无音轨，约 7.7 MB。

- [ ] **F3 数字不抖动**：专注运行时盯着倒计时秒位。
