请直接在当前已有的 Productivity Timer 项目上进行一次完整的视觉精修与主题升级，不要重新创建产品，不要破坏现有页面结构、计时逻辑和交互功能。

## 设计目标

将当前项目升级为一款以“深夜海洋、月光、潮汐与时间流动”为核心意象的高级专注计时应用。

设计主题命名为：

“Abyssal Reverie / 深海绮梦”

整体气质应当：

- 深沉但不压抑
- 浪漫但不甜腻
- 柔和但不模糊
- 精致但不堆砌
- 具有海洋感，但不能卡通化
- 具有流动感，但不能干扰专注
- 像一款成熟的付费级数字产品，而不是普通的蓝色主题换肤

页面全部使用中文。

中文字体优先使用：

`Microsoft YaHei, "微软雅黑", "PingFang SC", system-ui, sans-serif`

计时数字可以使用与微软雅黑协调的现代无衬线数字字体，但不能使用电竞、机械、赛博朋克或过度科幻的字体。

## 一、先进行视觉研究，再开始改造

在开始修改前，如果具备外部页面分析能力，请先浏览并学习 CraftFlow 的优秀 UI、Web、Product Design 和 AI Visual Concept 案例：

https://craftflow.art/inspiration

重点分析并尝试吸收以下特征：

- 大面积留白与视觉呼吸感
- 清晰且克制的信息层级
- 柔和、连续的线性构图
- 渐变、光影和空间深度的平衡
- 具有高级感的细线边界
- 简洁但富有表现力的视觉焦点
- 流畅而不过度的微交互
- 让装饰元素同时承担视觉引导作用
- 背景具有艺术性，但主体内容依然清晰
- 精致、现代、完整的产品化质感

不要直接复制某个案例，不要照搬其品牌、文案或具体组件。

应当提炼优秀案例的设计原则，再将这些原则转化为适合专注计时产品的原创设计语言。

## 三、核心设计语言：柔和的线性海洋

整个产品必须建立统一的“Soft Linear Ocean / 柔和线性海洋”视觉语言。

“线性”不是僵硬的直线，也不是普通科技网格，而是：

- 柔和连续的潮汐曲线
- 极细的月光轨迹
- 舒展的海浪轮廓线
- 缓慢延伸的航行路径
- 类似水流、等深线和风场的抽象线条
- 围绕计时器自然汇聚和扩散的曲线
- 具有方向性，但没有攻击性的视觉动势

线条必须：

- 纤细
- 连续
- 低对比度
- 疏密有致
- 大曲率
- 避免尖角
- 避免大量交叉
- 避免复杂科技线路
- 避免像股票图表或数据网络
- 避免密集等高线造成视觉噪声

所有页面元素都应当共享这种语言：

- 计时器使用潮汐圆环
- 卡片边界采用柔和细线
- 导航选中态使用一段流动光线
- 任务状态使用短小的潮汐轨迹
- 页面转场像海流推动内容
- 数据图表使用平滑曲线
- 分隔线像远处海平面，而不是机械横线

线条应当成为贯穿整个应用的视觉母题，而不是单独添加的装饰。

## 四、海洋背景

请为应用增加一个真正可感知到的海洋背景，而不仅是蓝色渐变。

背景应呈现“午夜海面逐渐通向深海”的写意场景：

### 背景上层

- 使用接近黑色的深海蓝天空
- 页面上方或偏左上方出现一片非常柔和的月光
- 月亮本体可以不直接出现，优先只表现朦胧光源
- 月光不能形成刺眼白色光斑
- 天空加入极少量雾化颗粒和几乎不可见的星点

### 背景中层

- 设置一条朦胧、柔和、略带弧度的海平线
- 海平线不能是一条生硬直线
- 在海面形成一条纵向、断续、自然扩散的银蓝色月光倒影
- 倒影应避开主要文字和关键按钮
- 远处海浪仅使用低对比度轮廓，不要描绘写实浪花

### 背景下层

- 页面下半部分逐渐进入更深、更安静的海蓝色
- 使用两至三层大尺度半透明波浪
- 波浪之间通过柔和线条和透明渐变产生纵深
- 可以加入非常稀疏的水下微粒或漂浮光尘
- 不要加入鱼、鲸、海豚、珊瑚、贝壳、船锚、椰树等直白装饰

背景优先通过高质量渐变、SVG曲线、模糊光层、噪点纹理和透明度叠加完成。

不要使用明显的图库海洋照片作为整页背景，不要让背景呈现壁纸感。它应该像为产品专门设计的数字海洋空间。

- Abyss Black Blue：`#030812`
- Midnight Navy：`#061321`
- Deep Ocean：`#08263A`
- Ocean Layer：`#0C3448`
- Tidal Teal：`#175466`
- Moonlit Cyan：`#76C7D0`
- Sea Mist：`#B7D8DC`
- Pearl White：`#EAF3F4`
- Twilight Lavender：`#8D8EBA`
- Twilight Rose：`#C08FA3`，仅作极少量浪漫点缀
- Primary Text：`rgba(240, 247, 248, 0.94)`
- Secondary Text：`rgba(202, 220, 224, 0.66)`

## 六、计时器视觉中心

计时器必须是页面唯一且明确的第一视觉焦点。

将计时器设计成“月光照亮的潮汐圆环”。

### 圆环结构

- 圆环由两至三层极细轨迹构成
- 外层是一条极低透明度的潮汐轮廓
- 中层表示计时进度
- 内层可以加入非常微弱的光晕或水面折射
- 不要使用粗重、饱满、塑料感的进度条
- 圆环整体应当纤细、轻盈、精确

### 计时进度

- 未完成轨道使用低透明度深海蓝
- 已完成部分使用银蓝到雾青的柔和渐变
- 进度端点可以有一个非常微小的月光亮点
- 亮点沿圆环缓慢移动，像远处灯塔或月光在海面上滑行
- 不要制作明显的发光火球效果

### 时间数字

- 数字清晰、稳定、宽松
- 使用 tabular numbers，防止计时过程中字符宽度变化
- 数字颜色接近珍珠白，但不能纯白刺眼
- 字重中等或偏轻，但必须保证可读性
- 时间数字周围保留充足留白
- 不要增加复杂阴影、立体描边或金属效果

### 运行状态

- 开始计时时，潮汐圆环逐渐苏醒并缓慢流动
- 暂停时，光线平滑减速并停留
- 继续时，从当前状态自然恢复
- 重置时，进度像潮水退去一样回落
- 完成时，以圆环为中心出现一次克制的水面涟漪
- 不要使用烟花、彩带、跳跃、剧烈缩放或游戏化庆祝动画

## 七、卡片与内容区域

保持现有内容结构，但重新优化视觉比例、间距与层级。

卡片设计要求：

- 使用深海色半透明表面
- 建议背景接近 `rgba(7, 28, 43, 0.66)`
- 使用极细冷色边界
- 圆角建议为16–22px
- 搭配宽而柔和的低透明度阴影
- 可以加入非常轻微的背景模糊
- 不要让所有卡片拥有完全相同的亮度
- 核心卡片稍亮，辅助卡片更安静
- 不要堆叠过多悬浮玻璃层

卡片边界可以在局部形成一段微亮的渐变线，如同月光扫过水面，但亮线不能围绕整张卡片持续高亮。

重新校准：

- 卡片之间的间距
- 标题与正文间距
- 图标与文字对齐
- 按钮高度
- 内边距
- 页面整体留白
- 信息密度
- 主次关系

让页面更舒展、更安静、更有呼吸感。

## 八、任务、记录与统计

### 当前任务

- 使用一条柔和的潮汐蓝线标记当前任务
- 可以加入一个极小的呼吸光点
- 当前任务要明显，但不能抢夺计时器的主视觉地位

### 已完成任务

- 使用低饱和海沫绿或银青色
- 删除线应当纤细
- 状态变化采用淡出、滑动或线条收束效果
- 不要使用刺眼绿色和大型勾选动画

### 数据统计

- 折线图采用平滑曲线，不使用尖锐折线
- 曲线下方可以有极淡的海蓝渐变面积
- 坐标轴和辅助线保持极低存在感
- 数据点默认隐藏或极小，悬停时再出现
- 柱状图如果保留，应使用圆角、窄柱和柔和渐变
- 不要让统计区域看起来像金融交易后台

### 专注记录

- 时间轴可以设计为一条缓慢延伸的航线
- 每一次专注记录是一枚细小的月光节点
- 当前日期稍亮，历史记录逐渐沉入较暗层级

## 九、导航、图标与控件

- 导航保持简洁、安静、低干扰
- 所有图标使用统一的细线型风格
- 图标线宽、圆角和视觉尺寸保持一致
- 优先使用圆润端点，不使用尖锐棱角
- 当前页面通过一条柔和的流动光线或半透明月光层表示
- 不使用厚重实色选中背景
- 不要添加复杂拟物图标

可以少量使用以下抽象意象：

- 月相
- 潮汐
- 海平线
- 航线
- 涟漪
- 罗盘弧线
- 水流轨迹

但不要直接使用具象海洋插画。

输入框、按钮、开关、下拉菜单和弹窗必须覆盖：

- Default
- Hover
- Focus
- Active
- Disabled
- Loading

Focus 状态必须清晰可见，不能只依赖细微颜色变化。

## 十、流动效果与微交互

所有动态效果都必须表现“时间像海水一样缓慢流动”。

### 背景动态

- 两至三层海流以不同速度缓慢横向漂移
- 建议完整周期为24–40秒
- 移动幅度保持很小
- 不同层之间形成轻微视差
- 动画必须首尾无缝
- 不要出现明显循环跳变

### 线条动态

- 柔和光线可以通过 stroke-dashoffset 缓慢流动
- 流动速度必须低
- 同一屏幕同时明显运动的线条不要超过三组
- 不要让所有边框持续发光或移动

### 鼠标交互

- 鼠标移动时，背景月光允许产生4–8px以内的轻微视差
- 卡片表面可以出现非常柔和的局部光照
- 光照必须低透明且缓慢跟随
- 不要添加强烈聚光灯或夸张磁吸效果

### 页面和组件过渡

- 页面进入：轻微上浮8–12px并淡入
- 元素错峰：控制在60–120ms
- 页面切换：220–320ms
- 卡片悬停缩放不超过1.01
- 按钮悬停上浮不超过2px
- 点击时轻微下沉
- 避免弹跳、果冻、旋转和大幅缩放

推荐缓动：

`cubic-bezier(0.22, 1, 0.36, 1)`

动画优先使用：

- transform
- opacity
- SVG stroke
- background-position

避免高成本、持续重绘的大面积滤镜动画。

支持 `prefers-reduced-motion`。用户关闭动态效果后，应停止背景漂移、鼠标视差和装饰线流动，只保留必要的状态反馈。

## 十一、响应式设计

保持并完善现有响应式结构。

### 桌面端

- 计时器位于明确视觉中心
- 任务和统计围绕核心区域平衡分布
- 背景海平线不能穿过主要文字
- 内容最大宽度合理，避免界面过度摊开

### 平板端

- 减少装饰线条数量
- 保持计时器尺寸和操作舒适度
- 卡片可以重新排列，但不能丢失信息

### 移动端

优先展示：

1. 计时器
2. 当前任务
3. 开始、暂停和继续
4. 今日进度
5. 其他记录与统计

移动端降低背景细节、模糊层级和粒子数量，确保流畅。

所有点击区域符合移动端触控要求。

## 十二、可读性与无障碍

- 不要为了营造深海氛围而牺牲文字对比度
- 正文不能使用过细字重
- 辅助文字仍需清晰可辨
- 主要按钮必须明确
- 键盘焦点必须可见
- 不能只依靠颜色区分任务状态
- 保证计时器在复杂背景上依然清晰
- 必要时在内容背后添加局部暗色遮罩，而不是直接删除背景细节
- 所有装饰性SVG和粒子不应阻挡点击与滚动

## 十三、禁止出现的效果

请主动检查并删除以下常见低质量表现：

- 普通蓝紫色渐变模板
- 卡通海浪
- 海洋生物贴纸
- 写实海洋图库照片
- 廉价霓虹边框
- 强烈赛博朋克风
- 过度玻璃拟态
- 大量发光元素
- 密集粒子
- 夸张模糊
- 巨大胶囊按钮
- 所有卡片等亮度
- 所有元素一起运动
- 缺乏留白的信息堆叠
- 为了装饰而增加无功能组件
- 破坏原有计时和任务功能

## 十四、最终验收标准

完成后，请从视觉、交互和功能三个层面自行检查并继续精修，不要只完成第一版换色就停止。

最终界面必须达到以下感受：

“用户打开页面时，仿佛进入一片深夜海域。远处月光在海面上缓慢延伸，纤细的潮汐线围绕时间流动。所有任务、记录和数据都安静地悬浮在深海层次中。界面具有诗意与浪漫感，但依然清晰、克制、实用，能够让人平静下来并开始专注。”

重点检查：

- 是否仍然保留并正常运行全部计时功能
- 开始、暂停、继续、重置和完成状态是否正确
- 任务操作是否正常
- 导航和设置是否正常
- 计时数字是否稳定
- 背景海洋是否清晰可感知
- 线性设计语言是否覆盖整个产品
- 动效是否柔和、连贯且不过度
- 文字是否清晰
- 卡片是否具有足够层次
- 桌面端和移动端是否协调
- 是否存在廉价蓝色模板感
- 是否真正达到高级、优雅、精致的产品品质

如果初次结果仍显得普通，请继续进行第二轮视觉精修，重点优化背景空间感、线条曲率、月光层次、计时器细节、卡片透明度、组件间距和动态节奏，直到整体形成统一且具有辨识度的“深海绮梦”视觉系统。
